# Цифровая очередь нового поколения

Система управления электронной очередью для отделений обслуживания клиентов: онлайн-запись, цифровой талон на смартфоне, детерминированный алгоритм вызова по SLA (`due_at`), голосовое сопровождение зала, умная геолокационная маршрутизация и рабочие места сотрудников.

##  О проекте

Проект решает ключевые проблемы очередей в физических отделениях: неравномерную нагрузку на окна, долгое ожидание клиентов и отсутствие прозрачного прогнозирования. Система объединяет мобильный клиентский опыт, экранные табло в зале ожидания и автоматизированные рабочие места персонала в единый отказоустойчивый контур.

### Ключевые возможности

* ** Клиентский веб-кабинет**:
  * Получение талона без бумажного чека и физического терминала (QR-код или 1 клик на смартфоне).
  * Предварительная онлайн-запись на удобный слот времени.
  * Персональный трекинг очереди в реальном времени с расчетом ETA (оставшееся время ожидания).
  * «Умный маршрут» — алгоритм на базе геопозиции и текущей загрузки, рекомендующий оптимальное отделение ($T_{total} = T_{road} + T_{queue}$).
  * Geofencing (авто-подтверждение прибытия при приближении к отделению).

* ** Табло вызова зала (TV Board)**:
  * Полноэкранный информационный дисплей для телевизоров в зоне ожидания.
  * Двухтональный акустический гонг и синтез речи (голосовой диктор вызова клиента к окну).
  * Отображение активных вызовов и списка ожидающих номеров.

* **👩‍💼 Пульт оператора (`/operator`)**:
  * Вызов следующего талона по приоритету, завершение обслуживания, перенаправление клиентов между окнами.
  * Учет времени обслуживания и фиксация неявки (`NO_SHOW`).

* ** Панель руководителя отделения (`/admin`)**:
  * Мониторинг загрузки зала, активных окон и очередей в реальном времени.
  * Настройка политик приоритетов (веса живой очереди, онлайн-записи и защитного интервала от голодания талонов).
  * Аналитика качества обслуживания и выявление аномалий времени ожидания.

* ** Мультиканальные уведомления & интеграции**:
  * Доставка уведомлений о вызове через Transactional Outbox (Web Push, SMS, Telegram-бот).
  * Интеграция с голосовым ассистентом (навык Яндекс Алисы) и RAG AI-консультант.

### Запуск в Docker Compose

```bash
# 1. Клонирование репозитория
git clone https://github.com/dvaJf/po-htatech-electronic-queue.git
cd po-htatech-electronic-queue

# 2. Подготовка конфигурации окружения
cp .env.example .env

# 3. Сборка и фоновый запуск всех сервисов
docker compose up --build -d
```

После старта проверьте готовность бэкенда:
```bash
curl http://localhost:8080/ready
```

##  Архитектура ядра

* **Детерминированный расчет вызова (`due_at`)**: Каждому талону назначается срок целевого обслуживания на основе типа записи, весов приоритетов и динамического коэффициента ожидания, исключающего «голодание» (starvation) талонов в очереди.
* **Идемпотентность и целостность**: Переходы между состояниями талона строго валидируются через FSM. Операции вызова и смены статуса защищены от race conditions (`FOR UPDATE SKIP LOCKED`).
* **Transactional Outbox**: Фоновая доставка сообщений (Telegram, Push, SMS) сохраняется в рамках единой транзакции с изменением статуса талона, гарантируя доставку `at-least-once` без блокировки основного HTTP-потока.
